## ⚠️ 멀티 세션 충돌 방지 규칙 (요약)

1. 모든 작업 = [기능목록](기능목록-및-로드맵.md)의 **항목(ID)**. 시작 전 그 문서의 "진행중 현황"에 등록.
2. **1 기능 = 1 브랜치 = 1 PR** (브랜치명 = 기능ID).
3. 모듈 경계 안에서 작업 (모듈러 모놀리식) → 파일 충돌 최소화.
4. 상세 규칙은 [개발원칙-및-브랜치전략.md](개발원칙-및-브랜치전략.md).
