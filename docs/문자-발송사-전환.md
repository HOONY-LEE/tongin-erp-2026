# 문자 발송사 — 지금은 솔라피, 서울 이전 후 한국AI통신으로 (2026-11-18)

## 지금 상태

- **전화(대표번호·PC 전화·녹취)**: 한국AI통신.
- **문자(상담 콘솔 SMS·캠페인·알림)**: **솔라피**.
  - 운영 API(Render)에서 `SMS_VENDOR`를 지워서 솔라피로 나간다.
  - `SMS_LIVE=1`이라 모든 번호로 실제 발송된다. `SMS_ALLOWED_RECIPIENTS`는 지웠다.
- **캠페인 일괄 발송은 화면에서 막아 둠**: `apps/web/src/pages/CampaignEditor.tsx`의 `CAMPAIGN_SEND_BLOCKED = true`.
  - 운영 DB에 시연(DEMO) 고객 데이터가 섞여 있어서다.
  - 상담 콘솔 1:1 문자는 보낼 수 있다.

## 왜 한국AI통신 문자를 못 쓰나

- 한국AI통신은 **국외 IP에서 오는 문자 API 호출을 막는다**: `403 overseas_ip_blocked`.
- 운영 API는 Render **싱가포르**에서 돈다. 나가는 IP는 다른 Render 서비스와 같이 쓰는 대역이다.
  - 대역: `74.220.52.0/24`, `74.220.60.0/24`
- 한국AI통신 '국외 접속 예외'로는 풀기 어렵다.
  - IP를 **한 개씩만** 등록할 수 있다(대역 불가). 1영업일 승인과 증빙 서류가 필요하다.
  - Render IP는 계속 바뀌어서, 등록해도 곧 다시 막힌다.
- **서버를 국내 IP(AWS 서울)로 옮기면 예외 없이 된다.**
  - 계획: `infra` 메모 "AWS 서울 이전" — Lightsail 서울 DB와 컨테이너, 약 $25/월.

## 서울 이전 후 한국AI통신 문자로 바꾸는 법

1. 새 API 서버(AWS 서울)의 환경변수에 아래를 넣는다.
   - `SMS_VENDOR=kat`
   - `KAT_SMS_FROM=07052369711` — 발신번호. 한국AI통신 계정이 가진 번호만 된다.
   - `KAT_ACCOUNT_ID`, `KAT_API_KEY` — 전화용과 같다.
2. 서버를 다시 띄운 뒤, 상담 콘솔 → 상담 화면 → **[SMS]** 창 아래에 "한국AI통신으로 보냅니다"가 뜨는지 본다.
3. 본인 번호로 한 통 보내 본다.
   - 실패하면 고객 이력의 '문자 실패' 사유를 확인한다.
   - 여전히 `overseas_ip_blocked`이면 서버가 국내 IP인지 확인한다(한국AI통신 콘솔 → 국외 접속 예외 → 차단된 요청).
4. 다 되면 솔라피 키(`SOLAPI_*`)는 지워도 된다.
   - `SMS_VENDOR`를 지우면 언제든 솔라피로 돌아가니, 며칠 두고 지워도 된다.
   - 솔라피 콘솔에서 **자동 충전**이 켜져 있으면 끄고, 남은 충전금을 확인한다.
